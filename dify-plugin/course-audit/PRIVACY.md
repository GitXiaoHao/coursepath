# Privacy Policy

## Summary

This plugin collects nothing, stores nothing and transmits nothing.

## What is collected

Nothing. The plugin receives the tool parameters you pass in the workflow
(`completed`, `course`, `plan_json`) and uses them only for the duration of the call.

## What is stored

Nothing. No database, no cache, no temporary file is written outside the plugin
sandbox's own working directory, and that directory is discarded when the call ends.

## What is logged

Nothing by the plugin itself. The Dify platform may log workflow node inputs and
outputs according to your own deployment's logging policy; that is outside this
plugin's control.

## What is shared with third parties

Nothing. The plugin makes **no outbound network requests**: no telemetry, no analytics,
no crash reporting, no model provider calls.

## Student data

If you pass completed course codes, those values stay inside the process. We recommend
not passing student identifiers at all — course codes and credits are sufficient.

## Contact

Open an issue on the project repository linked from the plugin listing.
